# Smart College Placement Management System (ERP)

A complete MERN stack campus recruitment and placement management portal designed for colleges and universities.

## 🚀 Features

- **Multi-Role Portals**:
  - **Student Portal**: Profile management, CGPA tracking, active drive browsing, and one-click applications.
  - **Placement Officer Portal**: Comprehensive college placement rate analytics, department breakdowns, and candidate verification.
  - **Company Recruiter Portal**: Drive creation, candidate pipeline review, and status evaluation.
  - **Super Admin**: User governance and role administration.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, React Router v6, Axios, Lucide Icons, Custom CSS Design System
- **Backend**: Node.js, Express.js, MongoDB Atlas (Mongoose), JWT Authentication, Helmet, CORS
- **Hosting**: Unified single-server architecture ready for Render.com

## 🏃 Running Locally

```bash
# Install dependencies
npm run install:all

# Run the unified full-stack server
npm start
# App live at http://localhost:5000
```
